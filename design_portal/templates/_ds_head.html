{# The Dani Smith Design system, as every screen page loads it: Archivo, the token sheet, Tailwind configured so its utilities can only produce the system's values, and the app's UI layer on top. The Tailwind palette is remapped rather than extended. Every colour family (gray, green, red, brand, ...) resolves to the same greige ramp, so a utility such as text-green-600 still renders but can no longer introduce chroma: the system has no accent and no status colours. Radius is 0 and shadows are none for the same reason. Meaning that colour used to carry must be carried by words, signs (+/-), weight or a hairline instead. #}
